# Changelog

All notable changes to this module are documented in this file. The module follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-27

### Added

- General purpose and S3 Express One Zone directory buckets.
- Secure general purpose bucket defaults: AES256 encryption, blocked public access, and bucket-owner-enforced ownership.
- Optional KMS and dual-layer KMS encryption, SSE-C blocking, ACLs, bucket policies, ABAC, and Object Lock default retention.
- Versioning, lifecycle management, logging, replication, CORS, notifications, static websites, and access points.
- Intelligent-Tiering, Inventory, Analytics, request metrics, and S3 Metadata table configuration.
- Stable outputs for bucket identity, endpoints, Region, hosted zone, websites, directory buckets, and access points.
- Native Terraform tests, validated examples, generated documentation, linting, security scanning, and minimum/latest compatibility CI.
